# Ejecución local QA v0.3.0

1. Instalar dependencias: `python -m pip install -r requirements.txt`.
2. Iniciar: `python start_lab_qa.py`.
3. Abrir `http://127.0.0.1:8000/` si no se abre automáticamente.
4. Usar el fixture íntegramente sintético indicado en `docs/POST_CONFIRMATION_QA_DELTA_v0.3.0.md`.
5. Detener con `Ctrl+C` en la ventana del servidor.

No introducir datos reales. No activar `MODEL_MODE` real, SMTP, proveedores de pago ni servicios externos.
